2. Backend REST API

Quản lý phiên chơi & chống gian lận: Client gửi cược, server sinh kết quả ngẫu nhiên, trừ tiền cược và ghi nhận lịch sử giao dịch. Client không bao giờ tự tính điểm thưởng.

  • POST /api/spin: Thực hiện 1 lượt quay
  • GET /api/session: Truy vấn số dư và lịch sử
  • GET /api/paytable: Đồng bộ bảng trả thưởng cho Client
  • POST /api/simulate: Chạy stress test & kiểm định RTP
