1. Math Core & Dải Cuộn Ảo (Reel Strips)

Không gian ngẫu nhiên công bằng: 5 cuộn quay được cấu hình từ 5 dải số ảo (Virtual Reel Strips) với 54 vị trí mỗi dải, phân bổ đều đặn các số 1..9.

  • engine/reels.py: Cấu hình dải số ảo 54 stops x 5 reels
  • engine/rules.py: Bộ quy tắc trả thưởng (Tài/Xỉu, Chẵn/Lẻ, Thùng, Sảnh, Poker, Số đơn)
  • Center Payline (Row 1): Chỉ dòng giữa mới là dòng trúng thưởng hợp lệ
  • RNG Mật mã: crypto.getRandomValues / secrets đạt chuẩn GLI-19
02

2. Backend REST API Chống Gian Lận

Toàn quyền tính thưởng trên Server: Client gửi lệnh cược lên Server, Server quay RNG, trừ cược, tính thưởng và trả về kết quả đã kiểm chứng. Client không thể can thiệp số dư.

  • POST /api/spin: Đặt cược Base Spin + Cửa phụ và thực thi 1 lượt quay
  • GET /api/session: Truy vấn số dư ví, thống kê và telemetry 100 phiên soi cầu
  • GET /api/rules: Đồng bộ bảng tỷ lệ thưởng và danh mục cược
  • POST /api/reset: Nạp lại số dư ví người chơi về 10,000
  • POST /api/simulate: Chạy Monte Carlo 100 - 50,000 spins đo RTP thực tế
03

3. Tích Hợp Đa Nền Tảng (Cross-Platform)

Backend API thiết kế phi trạng thái (Stateless) và chuẩn REST/JSON, sẵn sàng tích hợp với bất kỳ giao diện người dùng nào:

  • HTML5 Web & Mobile Web: Chạy mượt trên mọi thiết bị qua Cloudflare Edge
  • Unity (C#) / Godot: Tích hợp vào game 3D / 2D mobile native
  • Telegram Mini App (TMA): Đóng gói chạy trực tiếp bên trong Telegram
  • Backend Serverless: 100% Cloudflare Workers / FastAPI tương thích kép

4. Quản Lý Đặt Cược & Giảm Cược (Bet Manager)

Kiểm soát vốn linh hoạt với 4 cơ chế bảo vệ: Cung cấp khả năng tinh chỉnh cược tối ưu cho người chơi:

  • 3 Chế Độ Thao Tác: [➕ Cược Thêm], [➖ Giảm Cược] (trừ 1 chip), [🗑️ Xóa Cửa] (hủy ngay cửa cược).
  • Chuột Phải (Right-Click): Giảm nhanh giá trị chip đang chọn mà không cần đổi chế độ.
  • Nút Xóa Nhanh ✕: Tích hợp trực tiếp trên chip cược tại mỗi ô.

  • Thao Tác Toàn Bàn: Nút [⚡ Nhân Đôi x2] và [🗑️ Xóa Tất Cả] tiện lợi.

5. Động Cơ Soi Cầu Baccarat Real-time (Roadmaps)

Hiển thị nhịp cầu chuẩn Casino: Trực quan hóa dữ liệu thống kê từ API /api/session để người chơi phân tích cầu:

  • Bảng Hạt Giọt Nước (Bead Plate): Ma trận 6 hàng dọc x N cột, ghi nhận kết quả theo thứ tự từ trên xuống dưới, hết cột chuyển sang cột tiếp theo bên phải.
